# Zeek Network Monitoring Module

This directory provides the minimum Zeek deployment needed for the Phase 1 evidence package:

- Running Zeek container status
- Real `conn.log` output generated by Zeek
- Elasticsearch ingestion proof for Zeek logs

## What This Module Does

1. Generates a small sample PCAP inside Docker.
2. Runs Zeek against that PCAP and writes JSON logs to `zeek/logs/current/conn.log`.
3. Ships `conn.log` to the main Elastic stack through Logstash on port `5044`.
4. Collects evidence files into `zeek/evidence/`.

## Prerequisites

- Docker running
- Main Elastic stack started from the repository root with `bash setup.sh`
- Port `5044` reachable on the host for Logstash JSON TCP input

## Quick Start

```bash
cd "/home/amrhamada/Documents/SIEM & Data Lake with Elastic Stack/zeek"
chmod +x setup-zeek.sh status-zeek.sh stop-zeek.sh collect-evidence.sh
./setup-zeek.sh
./status-zeek.sh
./collect-evidence.sh
```

## Common Issues

- `conn.log is empty`
  - Wait 10-20 seconds and rerun `./status-zeek.sh`
- `index_not_found_exception`
  - Start Elastic from the project root with `bash setup.sh`
  - Wait for Logstash to become healthy, then rerun `./collect-evidence.sh`
- `permission denied while trying to connect to the Docker daemon socket`
  - Use a user in the `docker` group or let the scripts fall back to `sudo docker compose`
